# 이어듣기 · AFTERPLAY

유튜브 공개 영상 링크로 나만의 재생목록을 만들고, 화면을 끄거나 다른 앱을 사용하는 동안 **오디오 스트림만** 재생하는 개인 설치용 Android 앱입니다.

## 설치와 사용

1. [릴리즈](https://github.com/youbby/afterplay/releases)에서 `AfterPlay-<버전>-release.apk`를 내려받아 설치합니다. 기존 공개 버전과 같은 키로 서명하여 앱을 삭제하지 않고 업데이트할 수 있습니다. Android 8.0(API 26) 이상이 필요합니다. APK를 연 브라우저/파일 앱에 ‘알 수 없는 앱 설치’를 허용해야 할 수 있습니다.
2. **새 목록**으로 재생목록을 만듭니다.
3. **목록추가**에서 유튜브 영상 링크를 붙여넣습니다. 유튜브 앱의 **공유 → 이어듣기**도 지원합니다.
4. **전체 재생** 또는 개별 곡을 누릅니다. 홈으로 이동하거나 화면을 꺼도 재생됩니다.
5. 앱 하단, 미디어 알림, 잠금화면에서 재생을 제어합니다. 재생/일시정지 버튼으로 음악을 멈추거나 이어듣습니다.
6. 재생바의 **수면 모드**에서 **20분 / 40분 / 60분** 중 하나를 선택하면 그 시간이 지난 뒤 재생이 종료됩니다. 남은 시간이 표시되며 옆의 × 또는 수면 모드 창의 **타이머 해제**로 취소할 수 있습니다.
7. 상단 **앱 정보 ⓘ → 퀵 설정에 실행 버튼 추가**로 알림창 퀵 설정에 **이어듣기** 버튼을 등록합니다. Android 13 이상에서는 시스템 추가 창을 띄우며, 이전 버전에서는 퀵 설정의 편집에서 직접 추가합니다. 버튼을 누르면 기존 앱 창을 엽니다.
8. **앱 정보 ⓘ → 업데이트 확인**에서 설치 버전과 GitHub의 최신 정식 릴리스를 비교합니다. 새 버전이 있으면 **APK 다운로드**로 브라우저에서 내려받아 설치할 수 있습니다. 확인 중에는 중복 요청을 막고, 연결 실패 시 다시 확인할 수 있습니다. 자동 다운로드·설치는 하지 않습니다.
9. **앱 정보 ⓘ → 문제 확인**에서 재생 끊김 기록을 봅니다. 실제 오디오 요청의 HTTP 응답·시간 초과, 네트워크 전환, 재버퍼링·잔여 버퍼, 오디오 포커스·출력 지연, 자동 복구, 화면·절전 상태를 기기 내에 기록합니다. 끊김 직후 **로그 복사**로 내용을 확인하거나 전달하고, **지우기**로 초기화할 수 있습니다. URL·IP·영상 제목·인증 정보는 저장하지 않으며 자동으로 외부에 보내지 않습니다. 최근 기록은 앱 재실행 후에도 남지만 저장 용량은 제한합니다. 로그는 원인 판단의 단서이며 네트워크 원인을 확정하는 검사는 아닙니다.
10. 앱 정보의 **+ 더보기**에서 기능 설명, 유의사항, YouTube 정책 변경 안내, 오픈소스·앱 소스 정보를 펼쳐 봅니다.

## 기능

- 여러 재생목록 생성, 이름 변경, 삭제, 기기 내 영구 저장(DataStore)
- 영상 제목/채널/썸네일 자동 조회, 같은 목록 내 중복 추가 방지
- 곡 순서 변경 및 삭제
- 곡 메뉴 → 다른 재생목록으로 이동 (대상에 이미 있으면 중복 없이 이동)
- 순차 재생, 이전/다음 곡, 탐색, 셔플, 한 곡/전체 반복
- 종료 후 셔플·반복 설정, 마지막 곡과 재생 위치 복원
- 재생목록별 마지막 위치 기억: 전체 재생 또는 같은 곡 선택 시 이어듣기
- 수면 타이머: 20분·40분·60분 프리셋, 남은 시간 표시, 변경/해제, 화면 꺼짐·백그라운드에서 재생 종료
- 연결 실패 시 현재 곡을 총 3회 시도한 뒤 다음 곡으로 이동하고, 다음 곡도 3회 실패하면 정지
- 한국어 음성 우선 재생, 한국어가 없으면 원본 음성 선택 (같은 음성 내에서는 고음질 우선)
- Media3 `MediaSessionService` 기반 백그라운드 오디오 재생
- 영상 데이터 없이 오디오만 요청하고 음질 유지, 재생 연결의 전체 요청 시간 제한 제거 및 최대 2분 선행 버퍼
- DeX와 다른 앱의 공유에서 기존 앱 창과 재생 세션 재사용
- 퀵 설정의 이어듣기 실행 버튼
- 시스템 오디오 포커스 처리 및 이어폰 연결 해제 시 일시정지
- 일반 watch 링크, youtu.be, Shorts, YouTube Music 영상 링크, 공유 텍스트 지원
- 로그인, API 키, 별도 서버 불필요

현재 재생 대기열은 재생을 시작할 때의 목록입니다. 재생 중인 목록에만 테두리를 표시하며, 다른 목록을 열어보아도 재생 목록 표시는 유지합니다. 목록 편집과 곡 이동은 다음 전체 재생부터 반영됩니다. 목록은 앱을 다시 실행해도 보관됩니다. 앱을 다시 열면 재생 대기열과 설정을 일시정지 상태로 복원합니다. 하단 재생 버튼 또는 해당 목록의 전체 재생으로 마지막 위치에서 이어듣습니다. 다른 곡을 직접 누르면 그 곡의 처음부터 시작합니다(해당 목록에서 마지막으로 듣던 곡은 이어서 재생). 영상이 끝까지 완료된 경우에는 처음부터 시작합니다.

재생 중에는 2초마다 위치를 저장하며, 일시정지·탐색·종료·정상 서비스 종료 때도 저장합니다. 운영체제의 갑작스러운 프로세스 종료나 강제 종료 직후에는 마지막 주기 저장 시점으로 복원되어 약 2초의 차이가 있을 수 있습니다. 앱을 열기만 해서는 오디오를 자동으로 재생하지 않습니다.

수면 타이머는 설정한 순간부터 경과 시간을 셉니다. 일시정지하거나 곡/목록을 바꿔도 계속되며, 다른 프리셋을 선택하면 그 순간부터 새로 시작합니다. 만료 시 마지막 곡/위치를 저장하고 재생을 종료합니다. 직접 재생을 종료하거나 서비스를 종료하면 타이머도 해제되며, 앱 강제 종료 후에는 다시 설정해야 합니다.

## 가로 집중 모드

- 자동 회전을 켜고 휴대폰을 가로로 돌리거나 너비 600dp 이상의 큰 창에서 열면 왼쪽에 현재 재생 정보·탐색·재생 제어·수면 모드를, 오른쪽에 날짜·시계 카드와 뽀모도로 카드를 표시합니다. 좌우는 같은 너비이며 내용은 세로 가운데에 배치합니다. 큰 화면에서는 오른쪽 두 카드도 같은 높이로 나눕니다.
- 현재 시각은 작게, 뽀모도로 남은 시간은 크게 표시합니다. 해 모양은 뽀모도로 실행 중에만 나타나는 화면 켜짐 상태 표시이며 날씨 기능은 포함하지 않습니다.
- 왼쪽 상단 재생목록 버튼으로 목록을 열고, 뒤로 버튼으로 현재 재생 화면으로 돌아갑니다.
- 자물쇠는 왼쪽 재생패널의 팔레트 옆에 표시합니다. 수면 모드는 세로모드와 동일하게 곡 정보 위에 배치합니다.
- 뽀모도로는 기본 25분 집중 → 5분 휴식을 반복하며, 기본 4회차 후 30분 긴 휴식으로 자동 전환합니다. 시작/일시정지/계속/전체 초기화/다음 단계로 이동을 지원합니다. 건너뛴 집중은 완료 횟수에 포함하지 않습니다.
- 음악과 뽀모도로는 독립적으로 동작합니다. 화면 회전·일시정지·앱 재실행 후에도 저장한 타이머 상태와 마감 시각을 기준으로 이어집니다. 별도 백그라운드 종료 알림은 제공하지 않습니다.
- 뽀모도로 **시작/계속 중에만 화면 켜짐과 가로 화면을 유지**합니다. 집중·휴식 단계가 진행되는 동안 기기를 세로로 돌려도 앱은 가로 화면을 유지합니다. 일시정지·초기화·시간 설정 저장 후에는 시작 전 회전 설정과 기기의 화면 꺼짐 설정을 따릅니다. 수동 상시 켜짐 버튼은 없습니다.
- 인증으로 터치 잠금만 풀어도 타이머가 실행 중이면 화면 켜짐과 가로 고정은 유지합니다. 다른 앱으로 이동하면 기기의 화면 꺼짐 설정을 따릅니다.
- **집중 시작/계속**을 누르면 앱의 터치와 뒤로 가기가 잠기고 자물쇠가 닫힙니다. 화면 배치와 재생·타이머 버튼은 그대로 유지하며, 자물쇠 버튼만 누를 수 있습니다. 닫힌 자물쇠를 눌러 기기에 등록된 지문 또는 패턴·PIN·비밀번호로 인증하면 자물쇠가 열리고 조작할 수 있습니다. 인증 취소 시 잠금이 유지되며, 화면 회전과 앱 재실행 후에도 유지합니다. 잠금을 풀어도 타이머와 음악은 계속 동작합니다. 열린 자물쇠를 누르면 다시 잠깁니다.
- 화면 잠금이 없는 기기는 시작 전에 기기 설정을 안내합니다. 지문이나 잠금 비밀번호는 Android 시스템에서 확인하며 앱에서 저장하지 않습니다. 보호 범위는 앱 화면이며 홈·시스템 알림창은 사용할 수 있습니다.
- 집중/휴식 시간이 끝나면 다음 단계로 전환하면서 **뽀모도로 카드만 약 10초간 테마 색상으로 반전**해 알립니다. 소리나 진동은 울리지 않습니다. 수동 건너뛰기와 오래전에 지난 단계에는 반전 알림을 표시하지 않습니다.

## 시간 설정과 테마

- 뽀모도로 왼쪽 상단의 **집중** 표시는 집중 실행 중에만 ON AIR 형태로 켜집니다. 일시정지·휴식 중에는 일반 스타일로 표시합니다.
- 시간 아래에는 설정한 반복 횟수만큼 **○ 미완료 · ● 완료 · △ 시작 후 중간 종료** 아이콘만 표시합니다. 집중을 시작하지 않고 건너뛴 회차는 ○로 남습니다. 초기화 버튼은 타이머와 아이콘을 모두 초기화하고, 긴 휴식이 끝나면 새로운 회차 묶음을 시작합니다.
- 세로 화면 상단 또는 가로 화면 왼쪽 상단의 팔레트 버튼에서 **테마 설정**을 엽니다. 뽀모도로 옆 조절 버튼은 테마 없는 전용 **뽀모도로 설정**을 엽니다.
- 집중 시간 **20~60분**, 휴식 시간 **5~10분**, 반복 횟수 **1~4회**, 긴 휴식 시간 **30~60분**을 설정합니다. **저장**하면 타이머와 회차 기록을 초기화하고 일시정지합니다. **취소**는 설정을 변경하지 않습니다. 음악 재생에는 영향을 주지 않습니다.
- 테마는 **버건디 크림 / 피치 블러시 / 허니 앰버 / 클래식 블루 / 슬레이트** 다섯 가지입니다. 선택 즉시 세로·가로 화면, 재생 컨트롤, 시계, 뽀모도로와 대화상자에 적용하고 저장합니다.
- 각 테마는 제공된 네 가지 색을 바탕으로 하며 본문·강조 글자는 가독성을 위해 명암을 조정합니다. 슬레이트는 어두운 테마, 나머지는 밝은 테마입니다. 기본값은 버건디 크림입니다.

## 빌드

Android Studio에서 이 폴더를 열거나 JDK 17 이상과 Android SDK 36을 설치한 뒤 실행합니다. 첫 빌드는 Maven/Google/JitPack에 접속합니다.

```powershell
.\build-apk.ps1 -Test
```

Android Studio의 기본 JDK 및 SDK 경로는 스크립트가 자동으로 찾습니다. 다른 위치에 설치했다면 `JAVA_HOME`, `ANDROID_HOME`을 지정하세요. macOS/Linux에서는 `./gradlew assembleDebug testDebugUnitTest lintDebug`를 사용할 수 있습니다.

설치 파일은 `artifacts/AfterPlay-1.6.1-debug.apk`와 `app/build/outputs/apk/debug/app-debug.apk`에 생성됩니다. 개인 설치용 debug 서명을 사용합니다. 동일한 기기에 업데이트하려면 동일한 개발용 서명 키로 빌드해야 합니다. 스토어 제출용 서명은 포함하지 않습니다.

공개 배포용 APK는 기존 배포 키를 한 번 등록한 뒤 여기서 빌드할 수 있습니다. Windows PowerShell에서 다음을 실행하면 비밀번호 입력창이 열립니다. 키 비밀번호가 저장소 비밀번호와 같으면 두 번째 칸은 비워 둡니다.

```powershell
.\configure-signing.ps1 -KeystorePath 'C:\project\keys\afterplay-release.jks' -KeyAlias 'afterplay'
.\build-apk.ps1 -Release -Test
```

비밀번호는 Windows DPAPI로 암호화한 `.signing/release.clixml`에 저장하며 같은 PC의 같은 Windows 계정에서만 복호화할 수 있습니다. `.signing/`, 키 파일, Android Studio의 `app/release/` 출력은 Git에서 제외합니다. 키 파일과 비밀번호는 별도로 백업해야 하며, 다른 PC나 Windows 계정에서는 등록 명령을 다시 실행합니다.

`-Release` 빌드는 정렬과 서명을 수행하고 기존 공개 버전의 서명 인증서와 같은지 확인한 뒤 `artifacts/AfterPlay-<버전>-release.apk`를 생성합니다. 서명이나 인증서 확인에 실패하면 배포 폴더로 복사하지 않습니다. 다음 버전은 `app/build.gradle.kts`의 `versionName`과 `versionCode`를 올리고 같은 키로 빌드합니다.

## 검증

```powershell
.\gradlew.bat testDebugUnitTest lintDebug
# 에뮬레이터 없이 유튜브 추출/오디오 응답 확인
.\gradlew.bat testDebugUnitTest -PyoutubeNetwork=true
# 에뮬레이터/기기를 연결한 뒤: UI, 실제 미디어 서비스의 백그라운드 재생 테스트

# 공개 유튜브 영상 추출 및 오디오 재생까지 확인하는 네트워크 테스트
.\gradlew.bat connectedDebugAndroidTest -Pandroid.testInstrumentationRunnerArguments.youtubeNetwork=true
```

네트워크 테스트는 기본적으로 건너뜁니다. 실제 유튜브와 해당 네트워크의 접근 상태에 영향을 받습니다. 로컬 WAV 재생 테스트는 안드로이드 서비스의 재생 지속/자동 다음 곡/일시정지를 검증하며, 유튜브 추출 성공을 대신하지 않습니다. 기기 네트워크 테스트에서는 공개 영상 재생을 시작한 뒤 앱을 백그라운드로 옮기고 화면을 꺼 재생 지속을 확인합니다.

## 지원 범위

- 인터넷 연결이 필요합니다. 영상/오디오 다운로드 및 오프라인 저장 기능은 없습니다.
- 공개된 일반 영상만 지원합니다. 로그인, 비공개, 유료, 지역/연령 제한, 실시간 방송 지원을 보장하지 않습니다. 접근 제한을 해제하는 기능은 없습니다.
- 재생목록은 앱 안에서 만듭니다. 유튜브 재생목록 URL 전체 가져오기나 계정 동기화는 포함하지 않습니다.
- YouTube 공식 API 정책은 음성 분리와 백그라운드 플레이어를 허용하지 않습니다. 이 앱은 공식 API나 임베디드 플레이어 대신 NewPipe Extractor를 사용하며 YouTube의 공식·승인된 앱이 아닙니다. 개인용 APK로 제작했으며 정책 준수나 스토어 배포 가능성을 보장하지 않습니다.
- YouTube 변경, 요청 제한, 봇 확인에 따라 추출/재생이 실패할 수 있습니다. 이 경우 네트워크를 확인하거나 `app/build.gradle.kts`의 NewPipe Extractor를 호환 버전으로 업데이트해야 합니다.
- 일부 제조사의 강한 절전 설정이나 사용자의 강제 종료는 재생 서비스를 중단할 수 있습니다.

참고: [YouTube API 정책](https://developers.google.com/youtube/terms/developer-policies), [Media3 백그라운드 재생](https://developer.android.com/media/media3/session/background-playback), [NewPipe Extractor](https://github.com/TeamNewPipe/NewPipeExtractor).

## 구성

- `data/Models.kt`: URL 검증과 재생목록 연산
- `data/LibraryStore.kt`: DataStore 저장소
- `playback/YoutubeRepository.kt`: HTTP 다운로드 어댑터, 오디오 추출, 짧은 메모리 캐시
- `playback/PlaybackService.kt`: 재생 직전 URL 해석, ExoPlayer 및 미디어 세션
- `playback/PlaybackStore.kt`: 재생 대기열, 목록별 마지막 곡/위치, 셔플/반복 및 선택한 목록 저장
- `playback/SleepTimer.kt`: 서비스 수명에 묶인 수면 타이머, 경과 시간 기준 마감, 화면 꺼짐 중 만료 처리
- `PlayerViewModel.kt`: 라이브러리 및 미디어 컨트롤러 상태
- `ui/AfterPlayScreen.kt`: 한국어 Jetpack Compose UI

스트림 주소는 디스크에 저장하지 않고 각 곡의 로딩 시점에 해석합니다. 오디오 스트림만 ExoPlayer에 전달합니다. API 키/쿠키/사용자 계정 정보는 사용하지 않습니다. 영상 메타데이터, 스트림, 썸네일 요청은 YouTube/Google 서버로 전송됩니다.
